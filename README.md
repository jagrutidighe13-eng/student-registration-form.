# Student Registration Form

## About the Project
This is my beginner-friendly web development project built using HTML. It allows students to enter their personal details and select their preferred course through a registration form.

## Features
- Full name input
- Email address input
- Phone number input
- Course selection dropdown
- Gender selection
- Date of birth field
- Required-field validation
- Register and Clear Form buttons

## Technologies Used
- HTML5

## What I Learned
- Basic HTML document structure
- HTML form elements and input types
- Labels, dropdowns, radio buttons, and checkboxes
- Basic browser form validation

## How to Run
1. Download or clone this repository.
2. Open the `index.html` file in a web browser.
3. Fill in the registration form and test its fields.
